# استخدام النسخة الحالية

1. ثبّت APK.
2. افتح التطبيق واضغط **ربط الهاتف بنقرة واحدة**.
3. في Android Accessibility فعّل **Universal Creative Agent** مرة واحدة.
4. ارجع للتطبيق؛ ستتغير الحالة تلقائيًا عند اكتشاف الخدمة.
5. اكتب طلبك أو استخدم زر الصوت.
6. أرفق الوسائط من زر الإضافة.
7. راجع خطة التنفيذ ثم اضغط **تنفيذ الآن**.
