# مواصفات دورة المهمة

هذه الطبقة هي العقدة المركزية لسلوك الوكيل طويل التشغيل.

## القاعدة الأساسية

لا تُعرض مشكلة للمستخدم قبل استنفاد محاولات الحل الآلي الآمنة. عند ظهور عائق:

1. إعادة الملاحظة.
2. تشخيص السبب.
3. تجربة إصلاح آلي.
4. تجربة مسار بديل عند توفره.
5. التحقق من النتيجة.
6. الانتقال إلى تدخل بشري فقط إذا كان السبب فعلًا يحتاج الإنسان.

## تدخل بشري

الحالات المسموح بتحويلها للمستخدم تشمل التسجيل، التحقق، الاشتراك، ونطاقات الأذونات التي تتطلب قرارًا بشريًا.

كل طلب تدخل يرتبط بنقطة حفظ، ويحمل الخطوة التالية التي سيستأنف منها الوكيل.

## النتيجة

عند اكتمال المهمة تنتقل الحالة إلى جاهزة للمراجعة. يوافق المستخدم أو يطلب تعديلًا.

التعديل ليس مهمة جديدة؛ بل يحدد الخطوات المتأثرة ويعيد استخدام النتيجة والموارد السابقة.

## الأذونات

لكل تطبيق ملف مستقل يمكن أن يكون كاملًا، أو طلبًا في كل عملية، أو آمنًا. لا تُستخدم سياسة تطبيق لتغيير سياسة تطبيق آخر.

## التوسعة

المحركات الجديدة يجب أن تدخل عبر واجهات مستقلة: مهارة، مزود نموذج، محرك تنفيذ، محرك تحقق، أو محرك معاينة. لا تُربط ميزة جديدة مباشرة بقلب دورة المهمة إذا كان يمكن عزلها.
